# Demo Study Platform

> Educational Institute, Physical Library Management and Online Learning Platform Showcase Demo
> Built according to the [Website Project Requirements Client Confirmation](file:///c:/Users/rohitanshu.dhar/Desktop/demo-study-platform/Website_Project_Requirements_Client_Confirmation.pdf).

## Structure
- `client/`: Modern React (Vite) interface featuring public visitor landing, student account portal, and admin management console.
- `server/`: Node.js Express REST API with SQLite database, authentication, role-based controls, test engine, and mock payment pipeline.

## Running the Application
```bash
# Start both client and server concurrently
npm run dev

# Or start separately:
npm run dev:server
npm run dev:client
```
